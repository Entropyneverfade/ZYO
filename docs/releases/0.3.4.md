## 输入、输出与适用范围 / Inputs, outputs and scope

此次维护输入是上一公开提交`3f1720720590ea3940e76bbb104f00d68638c55d`的104文件基线，以及经确认的D2政策。输出是正式双语LICENSE、[历史MIT原文](../../LICENSES/MIT-legacy.txt)、[基线身份](../../LICENSES/MIT-BASELINE.json)、[逐范围清单](../../LICENSE-SCOPE.json)、[API独立条款](../API-TERMS.md)、统一包元数据和教程。

Inputs are the104-file baseline at public commit `3f1720720590ea3940e76bbb104f00d68638c55d` and the approved D2 policy. Outputs include formal bilingual terms, inherited MIT text, baseline identities, the scope schedule, separate API terms, synchronized packaging metadata and tutorials.

历史已有部分继续依MIT或各自第三方许可，包括已发布求解内核；新条款仅覆盖清单中有权授权的新创表达。许可证/元数据版本切换与算法性能里程碑分开记录。既有计算和图像以[0.3.3原小结](0.3.3.md)、[UC实测](../uc_results.md)的输入、引擎、数学模型和证据为准；旧图及通告按原版本保留。

Baseline portions retain MIT or their own third-party terms, including published solver kernels; new terms cover only eligible new expression in the schedule. License/metadata versioning is distinct from algorithm-performance milestones. Existing calculations/figures retain the inputs, engines, mathematical models and evidence in the0.3.3 and UC reports; historical figures and summaries are preserved under their original versions.

正式发布导出采用独立白名单，检查版本一致、混合许可表达、旧MIT全文及随包必需声明；负例覆盖声明缺失、旧署名改写、整包MIT/OR选项和范围版本错配。构建wheel/sdist后核对METADATA/PKG-INFO及安装后的许可文件。这样后续研发可逐版登记新增授权范围，研究者可识别其可用权限；API在实际服务、安全和资源验收后单独开通。

A dedicated export allowlist checks version identity, the mixed-license expression, inherited MIT text and required notices. Negative cases cover missing notices, changed attribution, blanket MIT/OR choices and scope-version mismatches. Wheel/sdist metadata and installed notices are checked. Future development can register each release's additions while researchers identify their rights; API access is separately activated after service, security and resource validation.
