## 使用价值与扩展 / Use and extension

认证LP便于课题组将原模型、数值解和最优性检查分离；共享预算便于复现实验并精确分析耗时。
对常规经济调度、连续容量规划等LP子问题可复用建模接口；整数启停应选择对应MILP路径。
小型公开开发题与大题Phase-I的性能分别记录，进一步开发以退化步数、准备段剖析和对偶算法为依赖。

Certified LP separates modeling, solving and optimality checks for reproducible research.
The common interface can serve continuous dispatch/planning subproblems; commitment binaries require
the separately selected MILP engine. Small public LPs and large Phase-I measurements have separate
scopes; subsequent work targets degeneracy, setup overhead and the dual algorithm contract.
